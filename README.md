# Bus Simulator Nusantara

Game simulator bus 3D (web, Three.js) dengan rute antar kota di Indonesia: terminal, SPBU, penumpang, telolet, kokpit FPP/TPP, dan spion yang berfungsi.

Main langsung di browser: https://malfain.github.io/bus-simulator-nusantara/

Kontrol keyboard: W/A/S/D nyetir · E pintu/isi BBM · H klakson · T telolet · V FPP/TPP · C kamera · F foto · Esc jeda.
Di HP muncul setir, pedal, dan tuas gigi di layar.
